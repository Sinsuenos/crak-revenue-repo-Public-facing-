# Brand Asset Library

Canonical brand assets live here. One asset per brand.
Reuse these everywhere — do not duplicate.

## Priority
1. Keep existing high-quality assets
2. Replace only poor-quality assets
3. Use official logos whenever possible
4. Never stretch, distort, or invent branding

## Fallback
If artwork cannot fit professionally:
- Use an official logo on a clean branded background
- If that fails: clean text card until a better asset is available

## Naming Convention
`{brand-slug}.png` — lowercase, hyphenated, no spaces.
